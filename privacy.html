プライバシーポリシー

GENKA MAP（以下「本サービス」）は、案件別の工数・原価を可視化するために必要な範囲で情報を取り扱います。

1. 取得する情報

本サービスのChrome拡張機能は、利用者が設定した計測対象サイトにおける、前面表示中のページのURL、ページタイトル、計測に必要なID、作業時間を取得します。Googleカレンダー連携を利用する場合は、利用者が明示的に許可したGoogleアカウントの予定について、予定タイトル、開始・終了時刻、予定IDおよび帰属判定に必要な参加者のメールドメインを取得します。

2. 取得しない情報

キー入力・マウス操作の内容、ドキュメント本文、スプレッドシートのセル値、対象外サイトの閲覧履歴は取得しません。Googleカレンダーの本文、場所、参加者のメールアドレスそのものは本サービスの保存先へ送信しません。

3. 利用目的と保存先

取得した情報は、顧客・案件・担当者ごとの工数集計、原価分析、ローデータの出力およびサービス運営のために利用します。

工数データは、当社が管理するクラウド環境（Google Workspace および Google Cloud Platform）に、導入企業ごとに分離して保存します。導入企業は、当社が提供するダッシュボードを通じて自社のデータを閲覧し、ローデータをCSVで出力できます。当社は取得した情報を、本サービスの提供と改善以外の目的には利用せず、第三者へ提供・販売しません。

保存期間は契約期間中および契約終了後6か月間とし、それ以降は削除します。契約期間中であっても、導入企業からのご依頼により速やかに削除します。

4. Googleユーザーデータの取り扱い

本サービスのChrome拡張機能「GENKA MAP」は、利用者本人がGoogleアカウントで明示的に許可した場合にかぎり、その利用者のGoogleカレンダーを読み取り専用スコープ（https://www.googleapis.com/auth/calendar.readonly）で参照します。訪問や電話会議など、ブラウザを操作しない作業時間を工数へ反映するためです。

  • 取得する情報：予定のタイトル、開始・終了時刻、予定ID、参加者メールアドレスのドメイン部分。
  • 取得しない情報：予定の本文、場所、参加者のメールアドレスそのもの。
  • 書き込み：カレンダーの作成・変更・削除は一切行いません。
  • 利用目的：顧客・案件別の工数集計のみに使用します。広告配信、販売、およびAIモデルの学習には利用しません。
  • 保存先：当社が管理するクラウド環境。導入企業ごとに分離して保存し、第三者へ提供しません。
  • アクセスの停止：拡張機能の設定画面「連携を解除」で、発行済みのアクセストークンを即時失効できます。Googleアカウントの権限管理画面からも取り消せます。

本サービスがGoogle APIから受け取った情報の利用および第三者への移転は、Limited Use要件を含む Google API Services User Data Policy に準拠します。

5. 連携の解除

利用者はChrome拡張機能の設定画面からGoogleカレンダー連携を解除できます。Googleアカウント側の権限管理画面から本サービスへのアクセスを取り消すこともできます。

6. 資料請求フォームで取得する情報

本サイトの資料請求フォームでは、会社名、お名前、メールアドレス、およびご記入いただいた場合のご相談内容を取得します。これらは、資料の送付、その後のご連絡、オンライン相談の日程調整および実施、ならびに本サービスのご案内のためにのみ利用し、ご本人の同意なく第三者へ提供しません。ご入力のメールアドレス宛に、資料のリンクを記載した自動返信メールを送信します。オンライン相談をご希望の場合は、日程調整のためにご希望日時や電話番号を別途うかがうことがあります。取得した情報は当社が管理するGoogleスプレッドシート等に保存し、利用目的の達成に必要な期間の経過後、または削除のご依頼に応じて速やかに削除します。

7. 本サイトのアクセス解析

本サイトでは、ページの改善のために自社でアクセス状況を計測しています。取得するのは、閲覧されたページのURLとタイトル、参照元サイトのURL、流入経路のパラメータ、ブラウザの種類・言語・画面幅、ページの滞在時間とスクロール到達率、クリックされたボタンの名称、および閲覧を区別するためにブラウザ内で生成したランダムな識別子です。氏名・メールアドレスなどご本人を特定できる情報やIPアドレスは取得せず、識別子から個人や所属企業を特定することはできません。

データは当社が管理するGoogleスプレッドシートに保存し、本サイトの改善のためにのみ利用します。広告配信事業者などの第三者へ提供することはなく、外部のアクセス解析サービスやトラッキング用Cookieは使用していません。ブラウザの設定でサイトデータの保存を無効にすると、識別子は保存されません。

8. お問い合わせ

本ポリシーまたは情報の取り扱い(削除のご依頼を含む)に関するお問い合わせは、info@genkamap.com までご連絡ください。
